# Бесконечный путь — frontend R2

Пудж автоматически идёт вперёд; игрок перемещается поперёк пути, целится и бросает крюк. Обычный крип и стрелок погибают от одного попадания, босс — от трёх отдельных кастов. Стрелки и боссы предупреждают о выстрелах. Вражеская пуля, контакт с живым крипом или его проход за спину заканчивают забег.

## Запуск

Нужен Node.js версии из `.nvmrc` и запущенный backend на порту 3001.

```sh
npm ci
npm run dev
```

Открыть `http://localhost:5173`. Vite перенаправляет `/api` на `http://127.0.0.1:3001`. Интернет/доступный сервер обязателен: без успешного `GET /api/v1/health` новый забег и продолжение недоступны. Перед новым забегом `/api/v1/catalog` проверяется на совместимость с этой сборкой. При потере связи бой ставится на паузу.

```sh
npm test
npm run build
```

Сборка находится в `dist/`. Для тестовой среды нужен HTTPS и тот же origin для `/api`; контейнерная настройка — в `deploy/`. `npm run preview` показывает статическую сборку и не заменяет reverse proxy для API.

## Управление

| Действие | ПК | Телефон, вертикально |
|---|---|---|
| Движение | A/D или ←/→ | Нижняя левая зона, относительное горизонтальное отклонение |
| Прицел | Мышь на игровом поле | Правое касание на игровом поле |
| Бросок | Новое нажатие ЛКМ | Отпустить правый палец после прицеливания |
| Пауза | Esc или кнопка | Кнопка паузы |

Удержание не повторяет бросок. Промах не корректируется автоматически. Новое нажатие необходимо после паузы. Скрытие вкладки, потеря фокуса, графического контекста или связи останавливают симуляцию; продолжение — только кнопкой и после проверки сервера.

## Границы R2

Подключены GLB героя, обычного крипа, крюка, цепи и окружения из пакета R1. Стрелок и увеличенный босс используют тот же риг с техническими моделями оружия, сигналами и метками. Анимации связаны с событиями боя, пауза замораживает позы. [Правила R2 и покрытие задач](docs/r2.md), [боевой генератор](docs/r2-combat.md), [контракт моделей R1](docs/r1.md).

Магазин, экономика, аккаунты, постоянные сохранения и галерея нескольких героев выходят в следующих релизах. R2 не начисляет золото или предметы. Забег хранится только в памяти текущей вкладки; перезагрузка его завершает. Счётчики всех трёх типов врагов представлены в итогах. Точки будущих магазинов существуют только в данных генератора.

## Модели для R2

Пакет стрелка, босса, снаряда и предупреждений доступен в [`public/models/r2/`](public/models/r2/). [Контракт и проверки](docs/models/r2/README.md), исходники Blender — в `assets/models/r2/`. Боевые правила R2 уже реализованы; подключение этих GLB вместо текущих технических моделей выполняется отдельным изменением клиента.

Графический комплект R2 (UI, декали, VFX и атласы) находится в [`assets/graphics/r2/`](assets/graphics/r2/README-R2.md). Он поставлен отдельно от моделей; подключение UI и VFX к игровым событиям входит в интеграцию ассетов.

## Устройство

- `src/game/` — чистая детерминированная симуляция 60 Гц и её тесты; без DOM и 3D-зависимостей.
- `src/platform/` — ввод и проверка доступности сервера.
- `src/presentation/` — Babylon.js, загрузка GLB, камера и адаптер анимаций; не принимает игровые решения.
- `src/main.ts` — состояния экрана, часы и связь модулей.
- `src/style.css` и `index.html` — русскоязычный HTML HUD.

Текущий стек закреплён в lockfile: TypeScript, Babylon.js, Vite и Vitest. Android/ПК-оболочки не входят в R1.
