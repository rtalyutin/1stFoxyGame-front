# Бесконечный путь — frontend R1

Первый браузерный боевой срез: Пудж автоматически идёт вперёд; игрок перемещается поперёк пути, целится и бросает крюк. Обычный крип погибает от одного попадания. Контакт с живым крипом или его проход за спину заканчивает забег.

## Запуск

Нужен Node.js версии из `.nvmrc` и запущенный backend на порту 3001.

```sh
npm ci
npm run dev
```

Открыть `http://localhost:5173`. Vite перенаправляет `/api` на `http://127.0.0.1:3001`. Интернет/доступный сервер обязателен: без успешного `GET /api/v1/health` новый забег и продолжение недоступны. При потере связи бой ставится на паузу.

```sh
npm test
npm run build
```

Сборка находится в `dist/`. Для тестовой среды нужен HTTPS и тот же origin для `/api`; контейнерная настройка — в `deploy/`. `npm run preview` показывает статическую сборку и не заменяет reverse proxy для API.

## Управление

| Действие | ПК | Телефон, вертикально |
|---|---|---|
| Движение | A/D или ←/→ | Нижняя левая зона, относительное горизонтальное отклонение |
| Прицел | Мышь на игровом поле | Правое касание на игровом поле |
| Бросок | Новое нажатие ЛКМ | Отпустить правый палец после прицеливания |
| Пауза | Esc или кнопка | Кнопка паузы |

Удержание не повторяет бросок. Промах не корректируется автоматически. Новое нажатие необходимо после паузы. Скрытие вкладки, потеря фокуса, графического контекста или связи останавливают симуляцию; продолжение — только кнопкой и после проверки сервера.

## Границы R1

Это временные геометрические модели для теста механики. Готовые модели делает владелец проекта отдельно. Требования к их интеграции описаны в [docs/r1.md](docs/r1.md).

Магазин, стрелки, боссы, экономика, аккаунты, постоянные сохранения и галерея нескольких героев выходят в следующих релизах. R1 не изображает сохранение золота или предметов. Забег хранится только в памяти текущей вкладки; перезагрузка его завершает. Счётчики сильных крипов/боссов на экране итогов равны нулю, поскольку эти противники ещё не включены.

## Устройство

- `src/game/` — чистая детерминированная симуляция 60 Гц и её тесты; без DOM и 3D-зависимостей.
- `src/platform/` — ввод и проверка доступности сервера.
- `src/presentation/` — Babylon.js, камера и временный blockout; не принимает игровые решения.
- `src/main.ts` — состояния экрана, часы и связь модулей.
- `src/style.css` и `index.html` — русскоязычный HTML HUD.

Текущий стек закреплён в lockfile: TypeScript, Babylon.js, Vite и Vitest. Android/ПК-оболочки не входят в R1.
