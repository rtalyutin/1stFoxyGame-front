# R2 — исходники и локальная проверка

Реализован полный маршрут120 клеток с четырьмя разрывами, лавой и горением, взрывающимся мобом, котом/сундуком и деревом/камнем/слизью. Настоящие блоки дома становятся неподвижным мостом; материалы не создаются. Сохранены безопасные первые два переноса, аккаунты, старые контенты/сборки, typed EAV, RLS, CAS и durable outbox.

Кандидат `r2-route-001` / `r2-map-1` / `r2-rules-1` / `house-full-route`. Авторские проверки: front51 PASS, back83 PASS, typecheck/build PASS; общий core/snapshot входит в оба набора, поэтому количества не складываются как уникальные тесты. Два настоящих API-процесса с общим PostgreSQL после потери checkpoint/finish ACK:1 PASS. Publisher/blue-green fixtures:9 PASS; это локальные HTTP fixtures, не целевой nginx.

Независимая QA:21 PASS /1 BLOCKED из22 семейств, плюс5 регрессий PASS,0 неожиданных browser errors. ПК1280×800 и эмуляция касаний844×390 прошли настоящий маршрут120 с обычными UI действиями, активными опасностями и серверным завершением. Исправлены найденные QA-R2-01 (порядок блоков менял опору/отскок после загрузки) и QA-R2-02 (информационная цель перехватывала касание). Пауза при настоящем повороте viewport проверена; native background/blur канал headless среды не дал проверить смену вкладки. Полный acceptance gate остаётся BLOCKED на этом наблюдении, source scope PASS.

Публикация исходников не является активацией игры. VPS operation NOT_STARTED: в сессии отсутствует доступ управления прежним сервером. Физический телефон, аппаратные FPS и внешняя доставка SMTP не проверены. Разрешение пользователя на публикацию и активацию сохраняется; дополнительного разрешения не требуется, нужен доступ и эксплуатационные readbacks.

Порядок целевого выпуска: явная аддитивная миграция → совместимый API → drain старого кода → immutable frontend pointer. Старые releases сохранять; откат на API без R2 после новых записей недопустим. См. `../deploy/README.md` и `../spec/R2-runtime-contract.md`.
