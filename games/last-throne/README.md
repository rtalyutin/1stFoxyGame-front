# Последний трон — браузерный клиент R2

`web/` — исходники готовой R2. Общая логика игры хранится в единственном месте: `1stFoxyGame-back/games/last-throne/core`. Клиент и сервер собираются из этой пары; второй редактируемой копии core здесь нет. Корневые сборка и маршруты первой игры не меняются.

Для локальной работы и проверки готовых R0/R1/R2 используйте `deploy/last-throne/assemble.mjs` из backend-репозитория. Аргументы и установка описаны в его `deploy/last-throne/README.md`. Требуется исходный `Last-Throne-R2.zip`; готовые версии и production-зависимости в Git не загружаются.

После сборки пары команды исходного TD запускаются из восстановленного общего каталога. Публичный маршрут на том же сервере — `/td/`. Его доступность нужно подтвердить на реальном сервере; наличие исходников в репозитории не означает публикацию игры.

Вход через существующий автомат зала готовится командой `hub/scripts/activate-last-throne.mjs`. Она проверяет фактический HTTPS endpoint, идентичность R2 и каждый файл клиента, затем создаёт отдельный каталог для `HUB_CATALOG_FILE`. Основной каталог остаётся с отметкой «Скоро» до установки. См. `docs/hub/README.md`.
