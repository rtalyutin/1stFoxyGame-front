# Придорожный магазин

Бирюзовый двойной шатёр с золотистой каймой, торговец с посохом, зелёный фонарь и товары. Исходные модели/рисованные текстуры Valve из локальной Dota; адаптация материалов PBR, tint/bakes и светящиеся кольца выполнены в Blender. Это не оригинальная с нуля геометрия.

Игровой файл `public/models/r3/shop.glb`: 15456 треугольников, 5 PBR материалов, статичный торговец без скелета/анимаций/физики Source2. Native: `assets/models/native/shop-v1/Runner-Forge-Shop-v1.blend`. Корень shop_root identity, Y вверх, +Z фасад; socket_shop_entry=(0,0,2.3), socket_shop_focus=(0,1.25,.2). Вход совпадает с зоной симуляции, фасад смотрит к дороге. Твёрдая геометрия за её 10м пределом, эмиссия экспортирована через glTF PBR.

Cadence задают только runtime.shopMinDistance/runtime.shopMaxDistance: 100/100 в новой immutable revision. Генерация при 100/200/300м, физическая точка на существующие36м вперёд: 136/236/336м. Старый забег сохраняет pinned balance. E/кнопка по-прежнему открывает магазин лишь после авторитетного подтверждения сервера; магазин замораживает бой, выход возвращает к забегу, повторный вход в использованную точку запрещён.
