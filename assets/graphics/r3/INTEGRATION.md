# Подключение R3

## Изображения и атласы

- PNG используют sRGB и straight alpha. Для UI и декалей — обычный alpha blend. Аддитивное смешивание VFX не требуется.
- Атласы содержат целочисленные прямоугольники; JSON даёт координаты от верхнего левого края и UV для Blender от нижнего левого. Atlas PNG собран из индивидуальных PNG без ресэмплинга.
- Для линейной фильтрации/mipmap добавить runtime UV inset или использовать индивидуальный PNG. В каждом ассете есть прозрачный отступ, но он не отменяет осторожность с выборкой соседней ячейки.
- SVG сохраняют формы отдельно, пригодны для редактирования. Растровый импорт PNG проще; прямой SVG импорт зависит от целевого пакета/версии движка. Не считать его выполненным.

## Blender

1. Моделировать магазин отдельно. Вывеска, полосы навеса, доски/болты и знак крафта — дополнительные декали, не готовая UV-развёртка.
2. Подложить тонкую плоскость над поверхностью, чтобы избежать z-fighting. Подключить Image Texture Color → Base Color и Alpha → Alpha. Режим прозрачности выбрать для своей версии Blender.
3. Одноцветные материалы использовать из `palette.json`/`palette.gpl` или `textures/solid`. Палитровый атлас 1024 × 512, 8 × 4 ячейки по 128 px; центр UV: u=(column+0.5)/8, v=1-(row+0.5)/4.
4. Покупка, изготовление и заморозка мира должны определяться логикой, а не видимостью декали.

## Runtime

Подготовить ссылки событий из events.json. Четыре кадра каждой последовательности выбираются по визуальной фазе 0..1; длительность не зашита и не задаёт механику. При SHOP существующие боевые эффекты заморожены вместе с миром.

Получение ресурса: сервер подтвердил → значение кошелька обновлено → частица летит к герою. Поражение до конца полёта не отменяет подтверждённую награду. Крафт и сохранение: pending до результата; подтверждённый успех запускает соответствующий flipbook. Timeout не разрешает показывать успех или создавать вторую покупку.

Вход профиля, истечение сессии, отсутствие сети, ошибка сервиса и восстановление используют нейтральные элементы. Поля логина и метод авторизации не определены графикой. Публичную регистрацию не добавлять.

Общие кнопки/панели модульные: их значения и подписи рисует runtime. Масштабировать/раскладывать их под экран, сохраняя зоны боя и читаемость угроз.

Не проверено: прямой импорт в выбранный движок, Blender-прозрачность/UV на реальных моделях, взаимодействие UI и экономические операции, целевой телефон. Предлагаемые компоненты и первый рецепт требуют принятой конфигурации игры.
