# Runner Forge — графика R4, v1

64 самостоятельных графических элемента, включая 18 предметных иконок (16 вариантов экипировки и 2 расходника), в принятом стиле R1–R2: простая геометрия, прежние 32 цвета, прозрачный фон. Все исходники SVG редактируемые; PNG экспортированы без фона.

## Состав

- 16 иконок экипировки: Быстрая катушка I–III, Длинное звено I, Сквозной зуб, Возвратный серп, Манжеты проводника I–III, Сапоги бокового шага I–III, Трофейный счётчик I–III, Часы должника.
- 2 иконки расходников: Пыль торможения и Флакон сборщика.
- 16 модульных элементов UI: владение, надевание, выбор, несовместимость, ожидание улучшения, нехватка ресурсов, ошибка, состояния расходника, пустые слоты, количество, сравнение и улучшение.
- 16 прозрачных накладок для поверхностей экипировки, по одной на нарисованный вариант предмета. Это отдельные декали, а не готовые UV-развёртки моделей.
- 6 спрайтов эффектов и 8 кадров двух коротких последовательностей: улучшение и активация расходника.
- 7 точных атласов PNG + SVG + JSON; палитра, 32 одноцветные текстуры, CSV, предложенный каталог, привязки событий и инструкция.

## Граница решения

Каталог P16 и раскладка P15 в ТЗ имеют статус предложения. Изображения подготовлены для этого предложения; названия, уровни и совместимость сохранены в `catalogue.json`. Графические ID этого пакета не объявляются существующими ID в коде. Для Длинного звена нарисован только I; лишние уровни и новые предметы не добавлены. Количество слотов не закреплено изображением интерфейса.

Цены, численные эффекты, рецепты, количества, длительности и клавиши выводит программа. Они не зашиты в рисунки. Часы должника представлены как предмет; бонус пассивного производства относится к R5 и здесь не оформлен. Герои и их специальные предметы R6 не добавлены.

## Использование

См. `INTEGRATION.md` и `events.json`. Модели, риги и анимации моделей пользователь делает отдельно в Blender. Комплект подготовлен для импорта; совместимость с конкретной игровой сборкой и моделями ещё не подтверждена.

`OVERVIEW.png` — компактный обзор предметов, `PREVIEW.png` — все 64 элемента, `ASSETS.csv` — список, `manifest.json` — размеры и контрольные суммы. Независимая проверка файлов выполнена: см. `VERIFICATION.md`.
