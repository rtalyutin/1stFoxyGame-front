# Blender: R2

1. Для простого low-poly материала использовать прежнюю палитру R1 (`palette.json`, `palette.gpl`) или отдельные 16 × 16 одноцветные Base Color PNG. `textures/palette_basecolor.png` — 512 × 256, 8 × 4 ячейки по 64 px. Центры UV: u=(column+0.5)/8, v=1-(row+0.5)/4.
2. Создать лица стрелка/босса геометрией. Декали глаз и рта накладывать отдельной тонкой плоскостью чуть выше поверхности, чтобы избежать z-fighting. Эти PNG прозрачные; они не являются полной UV-текстурой персонажа.
3. Для декали: Image Texture → цвет в Base Color, Alpha в Alpha; режим прозрачности материала выбрать в используемой версии Blender. Не импортировать шахматку как текстуру — в файлах настоящая прозрачность.
4. Шесть декалей лежат отдельно и в `atlases/model_decals.png` (1536 × 1024, ячейки 512 × 512). Точные UV для bottom-left находятся в JSON. Альфа-паддинг ячейки минимум 24 px. При mipmaps/линейной фильтрации использовать безопасный inset внутри ячейки или отдельный PNG.
5. Крип-стрелок отличается оружием и узкой подготовкой выстрела; босс — размером, широкой формой, знаком трёх заклёпок и отдельной реакцией на нелетальный удар. Сам по себе знак не заменяет различие геометрии.
6. Для runtime нужны модельные события: движение, начало прицеливания, выстрел, попадание, смерть; у босса также нелетальный зацеп/срыв и последнее попадание. Модели и эти клипы в пакет не включены.

Шейдеры, импорт материалов и анимации в Blender не проверены. Ссылки событий и направление спрайтов описаны в events.json.
