# Runner Forge — графический комплект R2

R2 добавляет стрелка и босса к комплекту R1. Сохранены простые плоские формы, крупные силуэты, палитра из 32 цветов и прозрачные PNG. Этот пакет — дополнение; R1 не перезаписывается.

## Состав

- 6 иконок UI, по 256 × 256: стрелок, босс, полная/снятая метка, предупреждение снаряда, срыв хука.
- 4 строки меток 3/2/1/0, по 768 × 256. Для иных принятых порогов метки собирает игра из отдельных иконок.
- 6 декалей для Blender, по 512 × 512: глаза/рот стрелка и босса, знаки стрелка и босса.
- 12 спрайтов VFX, по 256 × 256. Финальное попадание имеет точный редактируемый векторный исходник.
- 3 последовательности по 4 кадра: подготовка стрелка, подготовка босса, срыв хука. Атласы 1024 × 256; общий pivot 0.5/0.5. Время подготовки определяет игра, а не пакет.
- 7 атласов PNG + SVG + JSON с точной сеткой, PNG-координатами и Blender UV.
- Та же палитра JSON/GPL, заново экспортированные одноцветные текстуры и палитровый атлас; 32 цвета R1 без добавления новых цветов.

SVG — редактируемые исходники. PNG — sRGB, straight alpha, без фона. Предупреждения различаются формой: стрелок — круг и треугольник; босс — восьмиугольники. Срыв хука — разлетающиеся стальные зигзаги; успешное нелетальное попадание — замкнутый шестигранный удар; финальное попадание — звезда и осколки.

## Подключение

1. Использовать `events.json` как графические ссылки к уже принятой логике.
2. Для каждого фактического направления атаки поворачивать/проецировать отдельную стрелку и коридор. Локальный верх спрайта соответствует направлению вперёд. Количество направлений задаёт игра; три направления не зашиты.
3. Для последовательностей выбирать кадр по доле текущей фазы: 0..1. Общий pivot сохраняется. Для повторяющейся подготовки runtime может удерживать или повторять последовательность по своим правилам.
4. При зачтённом попадании уменьшать отображаемое количество полных меток. Урон/порог не определяются графикой.
5. Смешивание UI и декалей — обычное alpha blend. Аддитивное смешивание VFX необязательно; проверить на конкретной сцене.

## Границы комплекта

Нет моделей, ригов, анимаций моделей, аудио, магазина, лута, предметов или других героев. Модели пользователь делает отдельно в Blender. Анимации движения/подготовки/выстрела/попадания/смерти и реакции босса на срыв хука остаются отдельной работой.

Последствия попадания пули по герою (`P03`) остаются открытым игровым решением: нейтральный спрайт не означает мгновенную смерть и не вводит здоровье. Числа скорости, задержек и залпов, форма босса-надзирателя и ограничение одного зачёта за castId — предложения ТЗ до отдельного принятия. Графика не закрывает эти решения.

Основание: Runner-Forge-Release-Plan.xls, R2, D06–D09/F08–F12; Runner-Forge-GDD-TZ-v1.0.md §4/7/9/20/24; принятый простой стиль и R1-комплект; указание пользователя делать модели отдельно.

PNG/SVG, прозрачность, метки и точность атласов прошли независимую техническую и визуальную проверку. Импорт в Blender и поведение в игровом runtime ещё не проверены этим пакетным экспортом. Реакция пользователя на эстетику ещё не получена.
